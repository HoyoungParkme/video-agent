# 구현 계획

## 0. 이 문서가 다루는 것

11단계 CODE. 싱크독 개발 규약 DEV-11~15대로 작업을 슬라이스 카드로 자르고, 카드마다 커밋을 기록한다. **에이전트는 카드 하나를 받아 카드 안 참조만 따라간다.** 카드에 없는 함수를 짜게 되면 카드가 틀린 것이다 — 카드를 고치고, 필요하면 MINISPEC을 고친다.

슬라이스는 시나리오([[VA-SCN-001]]) 순서다 — S1 YouTube 자막 영상이 첫 슬라이스(B1). 기반 A가 끝나야 B가 시작되고, B1이 끝나면 자막 있는 YouTube 하나를 넣어 요약 · 챕터 · 스크립트를 읽을 수 있다. 그 뒤 받아쓰기(B2) → 질문(B3) → 다시 열기 · 내보내기 · 삭제(B4) → 잘 안 되는 경우(B5) → 통합 · 배포(C). 첫 배포를 써 본 사용자의 요구(2026-09-29 — 「분석 내용이 가시성이 없다」 · 「로컬 파일은 끌어 놓거나 골라서」)로 결과 그림 셋과 파일 올리기를 더했다 — 한눈에 보기(D1) → 대표 장면(D2) → 인포그래픽(D3) → 파일 올리기(D4). 하나가 끝날 때마다 쓸 수 있는 순서다. 두 번째 배포 뒤 사용자가 고른 다음 일(2026-10-01)로 카드 E를 더했다 — 새 텍스트 모델(E1) → 올리는 중 떠나기 확인(E2) → 받아쓰기 교체(E3, `whisper-1`이 2027-02-26에 없어진다) → 질문 맥락(E4). 작은 것부터다. 접근성(E5 — 초점 고리 · hover · 대비 · 한눈에 보기 키보드)은 사용자가 세 번째 디자인 캔버스를 승인한 뒤(2026-10-01) 더했다. 네 번째 배포 뒤 사용자가 고른 다음 일 셋(2026-10-01)으로 카드를 더한다 — 결과 화면 편하게(E6, 보이는 모양이 바뀌지 않아 캔버스 없이) → 영상 같이 보기(E7) → 보낸 추천 질문 · 상태 보드(E8). 사용자가 네 번째 디자인 캔버스(https://claude.ai/artifact/9QxpsbqKPbWNTw9ypVaNsL)를 승인해(2026-10-02) 명세를 위에서부터 고쳐 E7 · E8을 더했다. 상태 보드는 지금 모양 그대로 확정해 코드가 바뀌지 않는다. 다섯 번째 배포 뒤 사용자가 Google Drive에 있는 4.4GB 강의를 끌어 놓다가 물었다(2026-10-02) — 왜 올리는 동안 화면을 떠날 수 없고, 다시 보지도 못할 사본을 왜 올려야 하나. 올리지 않고 그 자리에서 읽는 Google Drive에서 고르기(F1)를 더한다 — 사용자가 다섯 번째 디자인 캔버스(https://claude.ai/artifact/TUm9bFZLztBEafJm3brPuX)를 승인해(2026-10-02) 명세를 위에서부터 고쳤다.

**카드는 호출 그래프로 닫혀 있다.** 카드의 함수가 부르는 함수는 같은 카드에 있거나, 선행 카드에서 끝났거나, 카드의 `스텁` 행에 적혀 있다. 스텁은 둘뿐 — 빈 결과, 또는 `not-implemented`(501). 조용히 다르게 동작하는 스텁은 없다. 스텁을 해제한 카드가 완료란에 그 사실을 적는다. `not-implemented`는 [[VA-API-001]] 2장 에러 표에 없는 임시 종류다 — `core/errors.py`의 `NotImplementedYet`(`urn:va:not-implemented`, 501)이 내고, 파이프라인 안에서 나면 작업이 `unknown`으로 실패한다. 스텁이 모두 풀리는 B4에서 지운다.

**화면이 있는 카드는 사람이 브라우저에서 와이어프레임 요소 번호대로 눌러 본다**(DEV-14 일곱째). 에이전트는 `tsc` · `build` · API 테스트까지다.

**커밋 규격** — `code(슬라이스): 함수명 — 요약`. 함수 하나 = 커밋 하나, docstring 첫 줄 = MINISPEC 항목 ID. PR = 슬라이스 하나. **커밋 메시지와 PR 본문에 에이전트 표시(`Co-Authored-By` · 세션 링크 · 「Generated with」)를 넣지 않는다** — 제목과 본문만 쓴다(싱크독 규약 STD-001 1.10, 사용자 결정 2026-09-22).

**진행 상황**: 카드 11장 **모두 완료**(A · B1 · B2 2026-09-23, B3 2026-09-27, B4 · B5 2026-09-28, C 2026-09-29, D1 ~ D4 2026-09-30 — PR #1 · #2 · #3 · #4 · #7 · #8 · #11 · #13 · #15 · #17 · #19). 스텁은 하나도 남지 않았다. **첫 배포**(2026-09-29): `dev` → `main` PR #12를 merge commit `3b3b2c4`로 머지했다 — 결정은 「에이전트는 PR만 열고 머지는 사용자가 merge commit으로」였고, 이번에는 사용자 지시(「너가 머지해」)로 에이전트가 머지했다. main에서 다시 띄운 스택이 그대로 돈다(첫 화면 · 키 확인 · 결과 넷 · 내보내기). **두 번째 배포**(2026-10-01): 카드 D1 ~ D4와 `fix(#18)`(PR #21 — 삭제 창의 대표 장면 · 인포그래픽)을 `dev` → `main` PR #20 merge commit `bab291c`로 머지했다 — 이번에도 사용자 지시(「지금 머지해 줘」)로 에이전트가 머지했다(결정은 그대로다). main에서 다시 띄운 스택이 그대로 돈다(첫 화면의 끌어 놓기 칸 · 키 확인 · 결과의 장면 · 인포그래픽 · 마이그레이션 0003 ~ 0005). **카드 E1 ~ E4**(2026-10-01 — PR #22 · #23 · #24 · #25)도 끝났다. 명세는 2026-10-01에 위에서부터 고쳤다(3장 10). **세 번째 배포**(2026-10-01): `dev` → `main` PR #26을 merge commit `d10b3fc`로 머지했다 — 사용자 지시(「지금 머지해 줘」)로 에이전트가 머지했다(결정은 그대로다). 작업 중에 Docker Desktop이 업데이트로 멈췄던 일이 있어, 사용자 요청(「도커에 문제가 있었어. 다시 해줘」)으로 머지 전에 이미지를 캐시 없이 다시 빌드하고 컨테이너를 새로 만들어 최종 코드로 다시 확인했다 — pytest 624 · 이미지 628 · E2E 58 · `check_code` 116, 진짜 스택에서 UI-5 · 떠나기 확인 · 20 ~ 40분 클립 분석(영상 9) · 질문 여섯(PR #26 댓글). main에서 스택이 그대로 돈다. **카드 E5**(2026-10-01 — PR #27 squash `ee3c3f6`)도 끝났다 — 세 번째 디자인 캔버스(https://claude.ai/artifact/HQyWTuusSvs3yktqEHaQ4p)를 사용자가 승인해(2026-10-01) [[VA-UI-001]] · [[VA-UI-002]]를 고치고 카드로 옮겼다. **네 번째 배포**(2026-10-01): `dev` → `main` PR #28을 merge commit `366fce0`로 머지했다 — 사용자 지시(「지금 머지해 줘」)로 에이전트가 머지했다(결정은 그대로다).
