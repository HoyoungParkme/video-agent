# USECASE (Cockburn)

## 0. 이 문서의 형식

Cockburn 유스케이스 템플릿을 따른다. 모든 유스케이스는 같은 12행 표 + 기본 흐름 + 확장으로 쓴다. 실패·대안은 전부 **확장**이며, `3a.`처럼 어느 단계에서 갈라지는지를 번호로 붙인다. 별도의 예외 절은 없다.

전체 15개. 사용자 목표 9개(추상 1 포함), 하위기능 6개.

**두 개의 축** — 목록은 액터로 묶고, 다이어그램은 패키지로 나눈다. 패키지는 사용자 행위 기준이다.

| 패키지 | 유스케이스 | 수 |
|---|---|---|
| 영상 넣기 | H0, H1, H2, H8, S1, S2, S3, S6 | 8 |
| 결과 읽기 | H3, H7, S4 | 3 |
| 질문하기 | H4 | 1 |
| 보관 | H5, H6, S5 | 3 |

**추상 유스케이스** — [[#UC-H0]] "영상을 분석한다"는 실제로 실행되지 않는다. [[#UC-H1]]·[[#UC-H2]]가 공통으로 가지는 "사전 안내 → 파이프라인 → 저장 → 결과 표시"를 묶은 것이며, 다이어그램에서 일반화 관계로만 나타난다.

**사용 형태**는 아직 미정([[VA-PRD-001]] 6절)이라 "화면"이라고만 쓴다. 웹 UI든 실행 파일이든 흐름은 같다.

## 1. 액터

| 액터 | 코드 | 설명 | 접근 경로 |
|---|---|---|---|
| 사용자 | H | 본인 한 명 ([[VA-SCN-001#P1]]). 영상을 넣고 결과를 읽고 질문한다 | 화면 |
| 시스템 | S | 영상 분석 에이전트 자체. 하위기능의 주 액터 | — |
| YouTube | — | 보조 액터. 영상 정보·자막·음성을 준다. 목표가 없으므로 코드 없음 | HTTP |
| OpenAI API | — | 보조 액터. 받아쓰기·요약·챕터·추천 질문·Q&A를 처리한다 ([[VA-PRD-001#N3]]) | HTTPS |

**시스템 경계**: 영상 분석 에이전트(화면 + 파이프라인 + 로컬 저장소)가 안쪽이다. YouTube, OpenAI, 사용자의 파일 시스템은 바깥이다.

**공통 이해관계자** — 개별 유스케이스에 반복해 적지 않는다.
- **사용자 본인** — 결과가 영상 내용과 어긋나지 않기를, 무엇이 외부로 나가는지 알기를 바란다 ([[VA-PRD-001#N3]])
- **API 비용을 내는 본인** — 예상치 못한 비용이 나가지 않기를 바란다 ([[VA-PRD-001#R8]])

#### UC-H0 영상을 분석한다 (추상)

| 항목 | 내용 |
|---|---|
| 범위 | 영상 분석 에이전트 |
| 수준 | 사용자 목표 (추상) |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | **사용자**: 영상 하나를 넣으면 요약·챕터·스크립트가 나오기를 바란다. |
| 사전조건 | OpenAI API 키가 설정되어 있다 ([[#UC-H8]]). |
| 최소 보장 | 실패해도 어느 단계에서 왜 실패했는지 남고, 이미 받아쓴 조각은 버려지지 않는다. |
| 성공 보장 | 결과(스크립트·핵심 요약·챕터·추천 질문)가 로컬에 저장되고 화면에 보인다. |
| 트리거 | 사용자가 영상을 지정하고 분석을 누른다. |
| 패키지 | 영상 넣기 |
| 포함(include) | [[#UC-S1]] (2번), [[#UC-S2]] (4번), [[#UC-S3]] (5번), [[#UC-S4]] (6번), [[#UC-S5]] (7번), [[#UC-S6]] (3~6번 내내) |
| 확장점(extension point) | `이미 분석한 영상` → [[#UC-H5]] |
| 일반화 | — (이 유스케이스가 [[#UC-H1]]·[[#UC-H2]]의 상위) |

**기본 흐름**
1. 사용자가 영상을 지정한다 (구체 방법은 H1·H2).
2. 시스템이 영상 정보와 길이를 확인하고 예상 소요 시간·API 비용을 보여 준다 ([[#UC-S1]]).
3. 사용자가 확인을 누른다.
4. 시스템이 자막 또는 음성을 확보한다 ([[#UC-S2]]).
5. 시스템이 받아쓰기한다 ([[#UC-S3]]). 자막을 확보한 경우 건너뛴다.
6. 시스템이 핵심 요약·챕터·추천 질문을 만든다 ([[#UC-S4]]).
7. 시스템이 결과를 저장한다 ([[#UC-S5]]).
8. 시스템이 결과 화면을 연다 ([[#UC-H3]]).

**확장**
- **2a. 같은 영상이 이미 분석되어 있다**
  - 2a1. 시스템이 "이미 분석한 영상"임을 알리고 저장된 결과를 연다 ([[#UC-H5]]). 파이프라인은 돌지 않는다.
- **2b. 길이가 상한(3시간)을 넘는다**
  - 2b1. 시스템이 길이를 보여 주며 지원하지 않는다고 알리고 멈춘다 ([[VA-PRD-001#N2]]).
- **3a. 사용자가 취소한다**
  - 3a1. 아무것도 전송되지 않고 끝난다.
- **4a~6a. 어느 단계든 실패한다**
  - 4a1. 시스템이 단계·이유를 보여 주고, 그 단계부터 다시 시도할 수 있게 한다 ([[#UC-S6]]).

#### UC-H3 분석 결과를 읽는다

| 항목 | 내용 |
|---|---|
| 범위 | 영상 분석 에이전트 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | **사용자**: 30초 안에 볼 가치를 판단하고, 원하는 구간을 바로 찾고 싶다. |
| 사전조건 | 분석 결과가 저장되어 있다 ([[#UC-S5]]). |
| 최소 보장 | 저장된 결과가 바뀌지 않는다. |
| 성공 보장 | 사용자가 핵심 요약·챕터·스크립트를 읽고, 시각을 눌러 해당 스크립트 위치로 이동할 수 있다. |
| 트리거 | 분석이 끝났거나([[#UC-H0]] 8번), 목록에서 영상을 열었다([[#UC-H5]]). |
| 패키지 | 결과 읽기 |
| 포함(include) | — |
| 확장점(extension point) | `질문한다` → [[#UC-H4]] · `내보낸다` → [[#UC-H7]] |
| 일반화 | — |

**기본 흐름**
1. 시스템이 결과 화면을 연다. 위에서 아래로 영상 정보 → 한 줄 요약 → 핵심 인사이트 → 챕터 요약 → 추천 질문 → 스크립트 → 질문창.
2. 사용자가 한 줄 요약과 핵심 인사이트를 읽는다 ([[VA-PRD-001#R4]]).
3. 사용자가 챕터 요약을 훑는다 ([[VA-PRD-001#R5]]).
4. 사용자가 인사이트의 출처 시각이나 챕터를 누른다.
5. 시스템이 스크립트를 그 시각 위치로 이동시키고 해당 구간을 강조한다 ([[VA-PRD-001#R3]]).
6. 사용자가 시각을 보고 원본 영상의 그 지점을 본다 (도구 밖).

**확장**
- **3a. 영상이 1시간을 넘어 챕터가 파트로 묶여 있다**
  - 3a1. 사용자가 파트를 펼쳐 그 안의 챕터만 읽는다 ([[VA-PRD-001#R5]]).
- **4a. 스크립트에서 거꾸로 찾는다**
  - 4a1. 사용자가 스크립트 문장을 누르면 그 문장의 시각이 보인다.
- **6a. YouTube 영상이다**
  - 6a1. 시각이 해당 시점으로 여는 YouTube 링크로 걸린다.

**연관**: [[VA-PRD-001#G1]] · [[VA-PRD-001#R3]] · [[VA-PRD-001#R4]] · [[VA-PRD-001#R5]] · [[VA-SCN-001#S1]] · [[VA-SCN-001#S3]]

#### UC-H4 영상에 질문한다

| 항목 | 내용 |
|---|---|
| 범위 | 영상 분석 에이전트 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | **사용자**: 요약에 없는 세부를 물으면 근거 시각과 함께 답을 받고 싶다. 지어낸 답은 원하지 않는다. |
| 사전조건 | 분석 결과(스크립트)가 저장되어 있다. OpenAI API 키가 설정되어 있다. |
| 최소 보장 | 답을 못 해도 이전 질문 기록은 남는다. |
| 성공 보장 | 근거 시각이 붙은 답변이 화면에 보이고, 질문·답변이 영상별 기록에 저장된다. |
| 트리거 | 사용자가 질문창에 질문을 넣거나 추천 질문을 누른다. |
| 패키지 | 질문하기 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 사용자가 질문을 넣는다.
2. 시스템이 이 영상의 스크립트와 앞선 질문·답변 기록을 맥락으로 OpenAI에 보낸다 ([[VA-PRD-001#N3]]).
3. 시스템이 답변과 근거 구간 시각을 받아 화면에 보여 준다 (10초 이내, [[VA-PRD-001#N1]]).
4. 시스템이 질문·답변을 영상별 기록에 저장한다 ([[VA-PRD-001#R7]]).
5. 사용자가 근거 시각을 눌러 스크립트의 그 위치로 이동한다 ([[#UC-H3]] 5번).

**확장**
- **1a. 추천 질문을 눌렀다**
  - 1a1. 그 질문이 질문창에 들어간 채로 2번으로 간다 ([[VA-PRD-001#R9]]).
- **1b. 이어지는 질문이다 ("그거 성능은?")**
  - 1b1. 2번에서 앞선 기록이 맥락으로 들어가므로 대명사가 풀린다.
- **3a. 영상에 없는 내용이다**
  - 3a1. 시스템이 "이 영상에서는 다루지 않습니다"라고 답한다. 근거 시각은 없다.
- **3b. 스크립트가 길어 한 번에 보낼 수 없다 (3시간)**
  - 3b1. 시스템이 질문과 관련된 구간을 먼저 골라 보낸다. 사용자에게는 같은 흐름이다.
- **2a. API 호출이 실패한다**
  - 2a1. 시스템이 이유를 보여 주고 다시 시도할 수 있게 한다.

3. 시스템이 한 줄 요약과 핵심 인사이트(5~8개, 1시간 넘으면 10개)를 만든다. 인사이트마다 출처 시각을 붙인다 ([[VA-PRD-001#R4]]).
4. 시스템이 추천 질문 3개를 만든다. 스크립트로 답할 수 있는 것만 ([[VA-PRD-001#R9]]).
5. 시스템이 인사이트·챕터의 시각이 스크립트 범위 안에 있는지 검사한다.
6. 시스템이 결과를 저장한다. 언어는 한국어.

**확장**
- **1a. 스크립트가 한 번에 보낼 크기를 넘는다 (시간 단위 영상)**
  - 1a1. 시스템이 시간 구간으로 나눠 구간별 챕터를 만든 뒤 합친다.
  - 1a2. 인사이트·한 줄 요약은 챕터 요약을 재료로 만든다.
- **2a. 영상이 1시간을 넘는다**
  - 2a1. 시스템이 챕터를 상위 파트로 묶는다.
- **5a. 시각이 스크립트 밖이거나 없다**
  - 5a1. 시스템이 그 항목을 다시 만들게 하거나, 가장 가까운 구간 시각으로 바꾼다.
- **1b~4b. API 호출이 실패한다**
  - 1b1. 시스템이 재시도하고, 실패하면 단계와 이유를 돌려준다. 스크립트는 보존된다.

**연관**: [[VA-PRD-001#R4]] · [[VA-PRD-001#R5]] · [[VA-PRD-001#R9]] · [[VA-PRD-001#N3]] · [[VA-SCN-001#S1]]

#### UC-S5 결과를 저장하고 중복을 판정한다

| 항목 | 내용 |
|---|---|
| 범위 | 영상 분석 에이전트 |
| 수준 | 하위기능 |
| 주 액터 | 시스템 (호출자: [[#UC-S1]], [[#UC-H0]]) |
| 이해관계자와 관심사 | **사용자**: 같은 영상을 두 번 분석해 비용을 이중으로 내고 싶지 않다. 결과는 내 PC에만 있기를 바란다. |
| 사전조건 | 출처 식별자가 있다. |
| 최소 보장 | 저장 실패 시 기존 결과가 손상되지 않는다. |
| 성공 보장 | 결과가 출처 식별자로 찾을 수 있게 로컬에 저장되고, 목록에 나타난다. |
| 트리거 | [[#UC-S1]] 4번(판정) 또는 [[#UC-H0]] 7번(저장). |
| 패키지 | 보관 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. (판정) 시스템이 출처 식별자로 저장소를 찾는다. 있으면 기존 결과를 돌려준다.
2. (저장) 시스템이 영상 정보·스크립트·핵심 요약·챕터·추천 질문을 식별자 아래 저장한다.
3. 시스템이 목록 항목(제목·출처·길이·분석 날짜)을 갱신한다.

**확장**
- **1a. 같은 YouTube 영상을 다른 URL 형식으로 넣었다 (watch vs youtu.be)**
  - 1a1. 식별자가 영상 ID이므로 같은 것으로 판정된다.
- **1b. 같은 파일을 다른 이름으로 넣었다**
  - 1b1. 식별자가 내용 해시이므로 같은 것으로 판정된다.
- **2a. 디스크가 부족하거나 쓸 수 없다**
  - 2a1. 시스템이 이유를 돌려준다. 이미 만든 결과는 메모리에 남아 재시도할 수 있다.
