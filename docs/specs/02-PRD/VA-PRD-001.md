# PRD — 제품 요구

## 1. 목표

#### G1 영상 하나를 넣으면 요약·타임라인이 나온다
로컬 파일이든 URL이든 영상 하나를 주면 읽을 수 있는 요약과 시간별 타임라인을 돌려준다. 근거: [[VA-RFQ-001#Q3]]

#### G2 분석된 영상에 대해 대화할 수 있다
요약을 읽은 뒤 궁금한 것을 물으면 영상 내용에 근거해 답한다. 근거: [[VA-RFQ-001#Q4]]

#### G3 혼자 쓰는 도구로 끝까지 동작한다
개인 PC(GPU 없는 WSL2)에서 설치해 쓸 수 있고, 릴리스 AI의 핵심 흐름을 한 바퀴 재현한다. 근거: [[VA-RFQ-001#Q5]]

## 2. 비목표

| 비목표 | 이유 |
|---|---|
| 여러 사용자·계정·권한 | 사용자가 본인 한 명. [[VA-RFQ-001]] 4절 |
| 여러 영상 일괄 처리 | 첫 프로젝트는 영상 하나 흐름에 집중. 필요해지면 다음 버전 |
| 화면(장면) 이미지 분석 | 첫 버전은 음성(받아쓰기) 기반으로 요약·Q&A를 만든다. 장면 인식은 GPU 없는 환경에서 비용이 크고, 릴리스 AI의 핵심 가치도 음성 기반이다. 미결사항 참조 |
| 로컬(오프라인) 받아쓰기 모드 | 받아쓰기·요약·Q&A는 OpenAI API로 한다([[#N3]]). GPU 없는 PC에서 로컬 모델은 1시간 영상에 수십 분~1시간 이상 걸려 [[#N1]] 목표를 못 맞춘다 |
| 실시간 스트림·CCTV | RFQ에서 선택하지 않음 |
| 영상 편집·클립 생성 | 분석 도구이지 편집 도구가 아니다 |

## 3. 요구사항

### 3.1 기능

#### R1 로컬 영상 파일 입력

근거: [[VA-RFQ-001#Q1]]

사용자가 PC에 있는 영상 파일을 지정하면 분석 대상으로 등록된다.

- [ ] mp4, mkv, mov, webm 파일을 받는다
- [ ] 영상 파일이 아니거나 열 수 없으면 이유를 알려 주고 멈춘다
- [ ] 음성만 있는 파일(mp3, m4a, wav)도 같은 흐름으로 받는다

#### R2 URL 영상 입력

근거: [[VA-RFQ-001#Q2]]

YouTube URL을 주면 영상(또는 음성)을 내려받아 [[#R1]]과 같은 흐름으로 분석한다.

- [ ] YouTube 동영상 URL(watch, youtu.be, shorts)을 받는다
- [ ] 제목·길이·채널명을 가져와 결과에 함께 보여 준다
- [ ] 내려받을 수 없는 URL(비공개, 삭제, 지역 제한)이면 이유를 알려 준다

#### R3 받아쓰기(스크립트)

근거: [[VA-RFQ-001#Q3]], [[VA-RFQ-001#Q4]]

영상의 음성을 텍스트로 바꾼다. 요약·타임라인·Q&A의 공통 재료이며, 사용자에게도 그대로 보여 준다. 받아쓰기는 OpenAI 음성 인식 API로 한다([[#N3]]).

- [ ] 문장(또는 구간) 단위로 시작·끝 시각이 붙은 스크립트를 만든다
- [ ] 한국어·영어 음성을 처리한다. 언어는 자동 감지한다
- [ ] YouTube 영상에 자막(수동 또는 자동 생성)이 있으면 받아쓰기 대신 자막을 가져와 쓴다 — 받아쓰기 비용과 시간을 없앤다
- [ ] 스크립트를 화면에서 읽을 수 있고, 각 구간을 누르면 해당 시각을 알 수 있다

#### R4 요약

근거: [[VA-RFQ-001#Q3]]

스크립트를 바탕으로 영상 전체를 요약한다.

- [ ] 한 문단 요약(3~5문장)과 핵심 포인트 목록(5개 안팎)을 만든다
- [ ] 요약은 영상 언어와 상관없이 한국어로 쓴다
- [ ] 스크립트에 없는 내용을 지어내지 않는다

#### R5 타임라인

근거: [[VA-RFQ-001#Q3]]

영상을 주제·장면 단위 구간으로 나누고, 구간마다 시작 시각과 제목·한 줄 설명을 붙인다.

- [ ] 구간은 시간 순서로 나열되고 시작 시각(mm:ss)이 붙는다
- [ ] 구간 수는 영상 길이에 비례한다 (10분 영상 기준 5~10개)
- [ ] 구간을 누르면 그 시각의 스크립트로 이동한다

#### R6 영상 Q&A

근거: [[VA-RFQ-001#Q4]]

분석이 끝난 영상에 대해 자연어로 질문하면 스크립트에 근거해 답한다.

- [ ] 답변에는 근거가 된 구간의 시각이 함께 붙는다
- [ ] 영상에 없는 내용을 물으면 "영상에서 다루지 않는다"고 답한다
- [ ] 같은 영상 안에서 이어지는 질문은 앞 대화 맥락을 유지한다

#### R7 분석 결과 저장·다시 보기

근거: [[VA-RFQ-001#Q4]] — Q&A는 분석 뒤 언제든 할 수 있어야 한다

분석 결과(스크립트·요약·타임라인)를 로컬에 저장해 두고, 나중에 다시 열어 읽거나 질문할 수 있다.

- [ ] 분석한 영상 목록을 볼 수 있다
- [ ] 같은 파일·URL을 다시 넣으면 다시 분석하지 않고 저장된 결과를 연다
- [ ] 결과를 삭제할 수 있다

#### R8 진행 상태 표시

근거: [[VA-RFQ-001#Q5]] — 혼자 쓰더라도 몇 분 걸리는 작업이라 멈춘 것처럼 보이면 안 된다

분석은 다운로드 → 받아쓰기 → 요약 순으로 시간이 걸리므로, 어느 단계에 있는지 보여 준다.

- [ ] 현재 단계와 대략의 진행률을 보여 준다
- [ ] 중간에 실패하면 어느 단계에서 왜 실패했는지 보여 준다

### 3.2 비기능

#### N1 GPU 없는 개인 PC에서 릴리스 AI 수준 속도

근거: [[VA-RFQ-001]] 4절 (WSL2, RAM 15GB, GPU 없음). 무거운 처리는 전부 API 서버가 하므로 이 PC의 성능은 병목이 아니다.

- [ ] GPU 없이 설치·실행된다
- [ ] 60분 영상의 전체 분석(받아쓰기·요약·타임라인)이 3분 이내에 끝난다
- [ ] YouTube 자막이 있는 영상은 1분 이내에 끝난다 ([[#R3]])

#### N2 영상 길이 상한

- [ ] 첫 버전은 60분까지 지원한다. 넘으면 시작 전에 알려 준다

#### N3 데이터 위치와 외부 API

받아쓰기·요약·타임라인·Q&A는 모두 **OpenAI API**로 한다. 사용자가 자기 API 키를 넣는다.

- [ ] 원본 영상·스크립트·결과는 내 PC에만 저장된다
- [ ] 외부로 나가는 것은 음성 트랙(받아쓰기용)과 스크립트 텍스트(요약·Q&A용)뿐이며, README와 설정 화면에 이 사실을 적는다
- [ ] API 키는 환경 변수 또는 설정 파일로 넣고, 저장소에 커밋되지 않는다
- [ ] API 키가 없거나 잘못됐으면 분석 시작 전에 알려 준다

#### N4 설치 단순함

- [ ] 사용자 한 명이 README를 보고 30분 안에 설치·첫 실행까지 간다

## 4. 성공지표

| 지표 | 목표 |
|---|---|
| 핵심 흐름 완주 | YouTube URL 하나 → 요약·타임라인 → 질문 3개 답변까지 한 번에 끝난다 |
| 요약 품질 | 직접 본 영상 5개에 대해 요약이 내용과 어긋나는 문장 0개 |
| Q&A 근거 | 답변 10개 중 9개 이상이 맞는 시각을 근거로 붙인다 |
| 처리 시간 | 60분 영상 → 3분 이내, 자막 있는 YouTube → 1분 이내 ([[#N1]]) |
| 재사용 | 분석한 영상을 다음 날 다시 열어 질문할 수 있다 ([[#R7]]) |

## 6. 미결사항

RFQ 6절 미정 7건 중 이 문서에서 **제안값을 넣은 것** — 승인 시 확정, 아니면 바꾼다.

- [ ] 스크립트 노출: **보여 준다**로 제안 ([[#R3]])
- [ ] 언어: **한국어·영어**로 제안 ([[#R3]])
- [ ] 길이 상한: **60분**으로 제안 ([[#N2]])
- [ ] 장면 분석: **첫 버전 제외(비목표)**로 제안
- [ ] 결과 저장: **저장한다**로 제안 ([[#R7]])
- [ ] 일괄 처리: **비목표**로 제안
