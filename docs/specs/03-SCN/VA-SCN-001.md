# 사용자 시나리오

## 0. 범위와 전제

- 사용자는 본인 한 명. 모든 시나리오의 주체는 [[#P1]]
- 사용 형태는 로컬 웹 UI([[VA-PRD-001]] 6절). 시나리오는 "화면"이라고만 쓰고 어느 화면인지는 화면 설계가 정한다
- 받아쓰기·요약·Q&A는 OpenAI API ([[VA-PRD-001#N3]]). 시나리오는 API 키가 이미 설정된 상태에서 시작하고, 없는 경우는 [[#S6]]에서 다룬다
- 결과 화면은 [[VA-PRD-001]] 3.1절의 조사 기반 요소(핵심 요약 · 챕터 요약 · 스크립트 · 추천 질문 · 채팅)로 이루어진다. 왼쪽 본문에 요약·인사이트·추천 질문·챕터, 오른쪽 고정 패널에 [스크립트]·[질문하기] 탭 — 배치는 화면 설계가 정했다. 여기에 그림 셋 — 한눈에 보기(타임라인·마인드맵) · 챕터 대표 장면 · 인포그래픽 — 을 더한다([[VA-PRD-001#R11]] · [[VA-PRD-001#R12]] · [[VA-PRD-001#R13]], 사용자가 첫 배포를 써 본 뒤 2026-09-29)
- 로컬 파일은 시간 단위 길이가 보통이라는 전제로 [[#S2]]를 쓴다

## 1. 페르소나

#### P1 강의·발표 영상을 많이 보는 개발자

**역할**: 데이터·AI 쪽 개발자. 공부 목적으로 YouTube 강연·컨퍼런스 발표·튜토리얼을 자주 본다. 회사 세미나·워크숍 녹화본 같은 로컬 파일도 있는데, 이건 대개 두세 시간짜리다.

**겪는 문제**:
- 1시간짜리 영상을 다 볼 시간이 없다. "볼 가치가 있나"를 먼저 알고 싶다
- 봤던 영상에서 "그 얘기가 몇 분쯤이었지"를 다시 찾느라 스크럽한다
- 릴리스 AI 같은 서비스는 편하지만, 어떻게 만드는지 직접 만들어 보고 싶다

**원하는 것**: 링크 하나 던지면 1분 안에 요약·챕터가 나오고, 궁금한 걸 물으면 "몇 분에 이런 말 했다"고 답해 주는 나만의 도구.

## 2. 시나리오

#### S1 YouTube 링크로 첫 분석 — 자막 있는 영상

**주체**: [[#P1]]
**상황**: 동료가 공유한 50분짜리 컨퍼런스 발표 링크. 볼지 말지 정하려고 요약부터 보고 싶다.

1. 화면에 YouTube URL을 붙여 넣고 분석을 시작한다
2. 영상 제목·채널·길이(50:12)가 바로 뜨고, "자막 있음 — 예상 약 1분, 받아쓰기 $0.00 + 요약·챕터·추천 질문 약 $0.02"가 표시된다 ([[VA-PRD-001#R2]], [[VA-PRD-001#R8]])
3. 진행 상태가 "자막 가져오는 중 → 핵심 요약 → 챕터 → 추천 질문 → 장면"으로 바뀐다 ([[VA-PRD-001#R8]])
4. 1분 안에 결과 화면이 열린다. 왼쪽 본문에 위에서 아래로, 오른쪽 패널에 스크립트:
   - **한눈에 보기**: 50:12 길이 막대 위에 챕터 12개 구간과 인사이트 8개의 시각 점, 한 줄 요약에서 챕터와 요점으로 뻗는 마인드맵 ([[VA-PRD-001#R11]])
   - **한 줄 요약**: "RAG 서비스를 운영하며 겪은 검색 품질 문제와 pgvector 기반 해결 과정을 공유하는 발표" ([[VA-PRD-001#R4]])
   - **핵심 인사이트 8개**: 각각 한두 문장 + 출처 시각. 예: "청킹 크기를 512에서 256으로 줄이자 재현율이 12%p 올랐다 `23:15`" ([[VA-PRD-001#R4]])
   - **추천 질문 3개**: "청킹 전략을 바꾼 근거는?", "pgvector 대신 검토한 대안은?", "운영 비용은 어떻게 달라졌나?" ([[VA-PRD-001#R9]])
   - **챕터 요약 12개**: `00:00 발표자 소개와 배경` / `04:30 문제 정의 — 검색이 왜 틀리나` / `12:40 아키텍처 개요` … 각 챕터 아래 글머리 2~3줄, 챕터마다 그 시작의 대표 장면(YouTube 미리 보기 썸네일) ([[VA-PRD-001#R5]], [[VA-PRD-001#R12]])
   - **전체 스크립트**(오른쪽 패널 [스크립트] 탭): 구간마다 시각 ([[VA-PRD-001#R3]]). [질문하기] 탭이 옆에 있다
5. 한눈에 보기와 한 줄 요약 · 인사이트만 보고 "볼 가치 있음"을 30초 만에 판단한다
6. 추천 질문 하나를 눌러 답을 본다 → [[#S4]]로 이어진다

**변형 — 자막이 없는 영상**: 2단계에 "자막 없음 — 받아쓰기 필요. 예상 약 3분, 받아쓰기 $0.30 + 요약 약 $0.02"가 뜨고, 3단계가 "음성 내려받는 중 → 받아쓰기 중 → …"으로 바뀐다. 나머지는 같다.
**변형 — 다른 영상이 분석 중**: 시작을 누르면 대기열에 들어가고 진행 화면에 "차례를 기다리는 중 — 앞 영상 1개가 끝나면 시작해요"가 보인다. 앞 것이 끝나면 저절로 시작된다 ([[VA-PRD-001#R8]]).
**변형 — shorts / youtu.be 링크**: URL 형식이 달라도 같은 흐름 ([[VA-PRD-001#R2]]).

**성공 조건**: URL 입력부터 핵심 요약이 보이기까지 1분 이내 ([[VA-PRD-001#N1]]). 인사이트 출처 시각을 눌렀을 때 실제로 그 말이 나온 지점이다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R2]], [[VA-PRD-001#R3]], [[VA-PRD-001#R4]], [[VA-PRD-001#R5]], [[VA-PRD-001#R8]], [[VA-PRD-001#R9]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]], [[VA-PRD-001#N1]]

#### S2 로컬 파일 분석 — 2시간 30분 워크숍 녹화본

**주체**: [[#P1]]
**상황**: 사내 워크숍 녹화본 `workshop_0912.mp4`(2시간 30분)가 PC에 있다. 외부 서비스에 올리기 애매해서 내 도구로 돌리고, 못 들은 뒷부분만 골라 보고 싶다.

1. 파일 탐색기에서 `workshop_0912.mp4`를 화면으로 끌어 놓는다. 올라가는 진행이 보이고(같은 PC 안이라 금방이다), 다 올라가면 앱이 파일을 확인한다. 올린 것은 앱 폴더의 사본이고 원본은 그대로다 ([[VA-PRD-001#R1]])
2. 길이 2:30:00이 확인되고(3시간 이하, [[VA-PRD-001#N2]]) "예상 약 8분, 받아쓰기 150분 × $0.006 = $0.90 + 요약 약 $0.02"와 "음성 조각과 스크립트 텍스트가 OpenAI로 전송됩니다. 영상 파일 자체는 나가지 않아요"가 뜬다. 확인을 누르면 시작된다 ([[VA-PRD-001#R8]], [[VA-PRD-001#N3]])
3. 진행 상태: "음성 추출 중 → 받아쓰기 중 조각 12 / 30, 남은 시간 약 4분 → 핵심 요약 → 챕터 → 추천 질문 → 장면". 12는 완료한 조각 수이고 조각 격자에 완료·받아쓰는 중·대기가 칸으로 보인다 ([[VA-PRD-001#R8]], [[VA-PRD-001#R3]])
4. 10분 안에 결과 화면이 열린다. [[#S1]] 4단계와 같은 구성이되, 인사이트는 10개, 챕터는 25개 안팎이 **파트 4개**(오전 세션 1·2, 오후 세션 1·2)로 접혀 있다. 한눈에 보기 막대에 파트 4개 구간이 보이고, 챕터마다 원본에서 뽑은 장면(발표 슬라이드)이 붙는다 ([[VA-PRD-001#R5]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]])
5. 마지막 파트를 펼쳐 못 들은 챕터 요약만 읽는다
6. 무엇이 전송되는지는 2단계의 사전 안내와 진행 화면의 전송 표시("음성 조각 → OpenAI whisper-1")로 알았다. 결과 화면에는 따로 없다 ([[VA-PRD-001#N3]])

**변형 — inbox 폴더에서 고르기**: 파일을 inbox 폴더에 넣어 두었으면 화면의 inbox 목록에서 골라 분석을 누른다. 사본을 만들지 않고 원본을 읽기만 한다. 파일 고르기 창으로 골라도 끌어 놓기와 같다 ([[VA-PRD-001#R1]]).
**변형 — 여러 파일을 한꺼번에 끌어 놓음**: "한 번에 한 파일씩 올려 주세요"가 뜨고 아무것도 올라가지 않는다 ([[VA-PRD-001#R1]]).
**변형 — 음성 파일(m4a)**: 녹음기로 딴 3시간 음성도 같은 흐름. 음성 추출 단계와 장면 단계를 건너뛰고, 챕터에 장면이 없다.
**변형 — 영상이 아닌 파일**: pdf를 끌어 놓거나 고르면 올리기 전에 "영상·음성 파일이 아닙니다"라고 알려 주고 멈춘다.
**변형 — 한국어 발표**: 받아쓰기가 한국어를 자동 감지한다. 요약은 어차피 한국어 ([[VA-PRD-001#R3]], [[VA-PRD-001#R4]]).
**변형 — 도중에 끊김**: 21번째 조각을 세 번 다시 보내도 네트워크가 안 되면 "받아쓰기가 멈췄어요 — 조각 21 / 30에서 실패 · 완료한 22개는 저장됨"이 뜬다(동시에 보내므로 뒤 조각이 먼저 끝날 수 있다). 다시 시도하면 완료하지 않은 첫 조각(21번째)부터 이어가고 끝난 조각은 다시 보내지 않는다 ([[VA-PRD-001#R8]]).

**성공 조건**: 2시간 30분 파일 → 10분 이내 ([[VA-PRD-001#N1]]). 3시간 분량 스크립트·챕터가 화면에서 버벅이지 않는다. 원본 파일과 결과는 PC에만 남고, 끌어 놓은 사본은 분석이 끝나면 지워진다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R1]], [[VA-PRD-001#R3]], [[VA-PRD-001#R4]], [[VA-PRD-001#R5]], [[VA-PRD-001#R8]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]], [[VA-PRD-001#N1]], [[VA-PRD-001#N2]], [[VA-PRD-001#N3]]

#### S3 챕터·인사이트로 원하는 구간 찾기

**주체**: [[#P1]]
**상황**: [[#S1]]의 발표를 보기로 했지만, 앞부분 회사 소개는 건너뛰고 본론부터 보고 싶다.

1. 결과 화면의 챕터 요약을 훑는다. 챕터마다 `시각 제목` + 글머리 요약이 보인다 ([[VA-PRD-001#R5]])
2. "12:40 아키텍처 개요" 챕터를 누른다
3. 스크립트가 12:40 위치로 이동해 그 부분 대사가 강조된다 ([[VA-PRD-001#R3]])
4. 시각을 보고 YouTube에서 그 지점부터 재생한다

**변형 — 인사이트에서**: 핵심 인사이트의 출처 시각 `23:15`를 누르면 그 발언이 있는 스크립트 위치로 간다 ([[VA-PRD-001#R4]]).
**변형 — 스크립트에서 거꾸로**: 스크립트를 읽다가 흥미로운 문장을 누르면 그 문장의 시각이 보인다.
**변형 — 한눈에 보기에서**: 결과 위쪽 막대의 챕터 구간이나 마인드맵의 챕터를 누르면 그 시각의 스크립트로 간다. 챕터 카드의 대표 장면으로 슬라이드가 바뀐 곳을 먼저 알아본다 ([[VA-PRD-001#R11]], [[VA-PRD-001#R12]]).

**성공 조건**: 챕터·인사이트 시각이 실제 영상의 해당 지점과 ±15초 안에서 맞는다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R3]], [[VA-PRD-001#R4]], [[VA-PRD-001#R5]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]]

#### S4 영상에 질문하기

**주체**: [[#P1]]
**상황**: [[#S1]]의 발표 요약을 읽었는데, 발표자가 어떤 DB를 썼는지가 요약엔 없다.

1. 결과 화면의 질문창에 "어떤 DB를 썼어?"라고 묻는다 ([[VA-PRD-001#R6]])
2. 답이 온다: "PostgreSQL을 썼고, 벡터 검색은 pgvector 확장으로 처리했다고 합니다. (근거 23:15, 24:02)"
3. 근거 시각을 누르면 스크립트의 그 위치로 이동한다 ([[VA-PRD-001#R3]])
4. 이어서 "그거 성능은 어땠대?"라고 묻는다. "그거"가 pgvector를 가리키는 걸 이해하고 답한다
5. "발표자 회사 매출은?"이라고 묻자 "이 영상에서는 다루지 않습니다"라고 답한다

**변형 — 추천 질문으로 시작**: [[#S1]] 6단계처럼 추천 질문을 누르면 1단계에 그 질문이 들어간 채로 시작한다 ([[VA-PRD-001#R9]]).
**변형 — 스크립트가 긴 경우(3시간)**: 답변 시간이 조금 늘 수 있지만 흐름은 같다.

**성공 조건**: 답변마다 근거 시각이 붙고, 그 시각의 대사가 실제로 답의 근거다. 영상에 없는 걸 지어내지 않는다.
**연관 요구사항**: [[VA-PRD-001#G2]], [[VA-PRD-001#R6]], [[VA-PRD-001#R9]], [[VA-PRD-001#R3]]

#### S5 며칠 뒤 다시 열어 질문하고 노트로 옮기기

**주체**: [[#P1]]
**상황**: 일주일 전 분석한 발표 내용이 갑자기 필요하다. 링크는 기억 안 나고 제목만 어렴풋하다.

1. 화면의 "분석한 영상" 목록을 연다. 제목·출처·길이·분석 날짜가 보인다 ([[VA-PRD-001#R7]])
2. 해당 영상을 골라 연다. 핵심 요약·챕터·스크립트가 그대로 있다. 다시 분석하지 않는다
3. 새 질문을 한다 ([[VA-PRD-001#R6]]). 지난주 질문 기록도 남아 있다
4. 결과를 마크다운으로 내보내 옵시디언 노트에 붙인다. 시각이 `[23:15]` 링크로 남아 노트에서 눌러도 YouTube 그 지점이 열린다. 노트에는 마인드맵 · 타임라인 그림과 챕터 장면이 들어가 옵시디언에서 그대로 보인다 ([[VA-PRD-001#R10]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]])
5. 필요 없어진 다른 영상 하나를 목록에서 삭제한다

**변형 — 같은 링크를 또 넣음**: 새로 분석하지 않고 "이미 분석한 영상입니다"라며 저장된 결과를 연다 ([[VA-PRD-001#R7]]).
**변형 — 같은 로컬 파일을 또 넣음**: 파일 내용이 같으면 마찬가지로 저장된 결과를 연다.
**변형 — 인포그래픽도 넣는다**: 내보내기 전에 [인포그래픽 만들기]를 누른다. 예상 비용 약 $0.006이 뜨고, 확인하면 한 장이 그려져 결과 화면에 보인다. 그림 속 글자 · 숫자는 틀릴 수 있다는 안내가 함께 있다. 이제 내보낸 노트에도 그 그림이 들어간다 ([[VA-PRD-001#R13]]).

**성공 조건**: 다시 여는 데 API 호출 없이 즉시 열린다. 내보낸 마크다운만 봐도 요약·챕터·시각을 알 수 있다. 삭제하면 목록·결과·스크립트·질문 기록이 모두 지워진다.
**연관 요구사항**: [[VA-PRD-001#G2]], [[VA-PRD-001#G3]], [[VA-PRD-001#R6]], [[VA-PRD-001#R7]], [[VA-PRD-001#R10]], [[VA-PRD-001#R11]], [[VA-PRD-001#R12]], [[VA-PRD-001#R13]], [[VA-PRD-001#N3]]

#### S6 잘 안 되는 경우들

**주체**: [[#P1]]
**상황**: 처음 설치했거나, 안 되는 입력을 넣었다.

1. **API 키 없이 시작**: 앱을 열자마자 맨 위 배너에 "OpenAI API 키가 없어서 아직 분석할 수 없어요"와 [키 넣으러 가기]가 보이고 분석 버튼은 막혀 있다. 누르면 설정 화면으로 가서 키를 넣고 확인하면 배너가 사라진다 ([[VA-PRD-001#N3]])
2. **비공개·삭제된 YouTube**: URL을 넣자 "이 영상은 비공개이거나 삭제되어 받을 수 없습니다"가 뜬다 ([[VA-PRD-001#R2]])
3. **4시간짜리 영상**: 제목·길이를 가져온 뒤 "3시간을 넘는 영상은 아직 지원하지 않습니다(4:12:30)"라며 시작 전에 멈춘다 ([[VA-PRD-001#N2]])
4. **분석 도중 실패**: 받아쓰기 단계에서 API 오류가 나면 "받아쓰기가 멈췄어요 — 조각 8 / 30에서 실패 · 완료한 7개는 저장됨"과 이유 한 줄이 뜨고, 완료하지 않은 첫 조각부터 다시 시도할 수 있다. 요약 단계에서 실패하면 "핵심 요약 단계가 멈췄어요 · 스크립트는 저장됨"이고 그 단계부터 다시 시도한다 ([[VA-PRD-001#R8]])

**변형 — 인터넷 끊김**: 로컬 파일이라도 받아쓰기는 API라서 "네트워크에 연결할 수 없습니다"로 4단계와 같이 처리된다. 인터넷이 없는 채로 앱을 켜면 배너에 "연결을 확인하지 못했어요 — 인터넷이 되면 분석 버튼을 누를 때 다시 확인합니다"가 뜨고, 키가 틀린 것과는 다른 문구다.
**변형 — 예상 비용 보고 취소**: 2시간 파일에 "비용 약 $0.7"이 떠서 취소를 누르면 아무것도 전송되지 않는다. 끌어 놓아 올린 파일이면 그 사본도 지워진다 ([[VA-PRD-001#R8]], [[VA-PRD-001#R1]]).
**변형 — 올리다 멈춤**: 끌어 놓은 파일이 올라가는 중에 멈추기를 누르거나 창을 닫으면 올라간 부분이 지워진다. 다시 끌어 놓으면 처음부터 올린다. 앱 폴더의 디스크가 모자라면 올리기 전에 "올릴 자리가 모자라요"라고 알려 준다 ([[VA-PRD-001#R1]]).
**변형 — 장면을 얻지 못함**: YouTube 미리 보기 썸네일이 없는 영상이면 장면 단계가 조용히 넘어가고 결과는 장면 없이 열린다 — 분석은 성공이다 ([[VA-PRD-001#R8]], [[VA-PRD-001#R12]]).
**변형 — 인포그래픽 실패**: [인포그래픽 만들기]가 실패하면 "인포그래픽을 만들지 못했어요 — {이유}"가 한 줄 뜨고 다시 누를 수 있다. 결과는 그대로다 ([[VA-PRD-001#R13]]).

**성공 조건**: 어떤 실패든 "무엇이, 어느 단계에서, 왜" 안 됐는지 한 줄로 알 수 있고, 프로그램이 죽지 않는다.
**연관 요구사항**: [[VA-PRD-001#G3]], [[VA-PRD-001#R1]], [[VA-PRD-001#R2]], [[VA-PRD-001#R8]], [[VA-PRD-001#R12]], [[VA-PRD-001#R13]], [[VA-PRD-001#N2]], [[VA-PRD-001#N3]], [[VA-PRD-001#N4]]
