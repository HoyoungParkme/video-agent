# 사용자 시나리오

## 0. 범위와 전제

- 사용자는 본인 한 명. 모든 시나리오의 주체는 [[#P1]]
- 사용 형태(웹 UI / 실행 파일)는 아직 미정([[VA-PRD-001]] 6절)이라 "화면"이라고만 쓴다. 어느 쪽이든 흐름은 같다
- 받아쓰기·요약·Q&A는 OpenAI API ([[VA-PRD-001#N3]]). 시나리오는 API 키가 이미 설정된 상태에서 시작하고, 없는 경우는 [[#S6]]에서 다룬다
- 릴리스 AI의 핵심 흐름(넣기 → 요약·타임라인 → 질문)을 기준으로 한다

## 1. 페르소나

#### P1 강의·발표 영상을 많이 보는 개발자

**역할**: 데이터·AI 쪽 개발자. 공부 목적으로 YouTube 강연·컨퍼런스 발표·튜토리얼을 자주 본다. 회사 세미나 녹화본 같은 로컬 파일도 있다.

**겪는 문제**:
- 1시간짜리 영상을 다 볼 시간이 없다. "볼 가치가 있나"를 먼저 알고 싶다
- 봤던 영상에서 "그 얘기가 몇 분쯤이었지"를 다시 찾느라 스크럽한다
- 릴리스 AI 같은 서비스는 편하지만, 어떻게 만드는지 직접 만들어 보고 싶다

**원하는 것**: 링크 하나 던지면 1분 안에 요약·타임라인이 나오고, 궁금한 걸 물으면 "몇 분에 이런 말 했다"고 답해 주는 나만의 도구.

## 2. 시나리오

#### S1 YouTube 링크로 첫 분석 — 자막 있는 영상

**주체**: [[#P1]]
**상황**: 동료가 공유한 50분짜리 컨퍼런스 발표 링크. 볼지 말지 정하려고 요약부터 보고 싶다.

1. 화면에 YouTube URL을 붙여 넣고 분석을 시작한다
2. 영상 제목·채널·길이가 바로 뜬다 ([[VA-PRD-001#R2]])
3. 진행 상태가 "자막 가져오는 중 → 요약 만드는 중 → 타임라인 만드는 중"으로 바뀐다 ([[VA-PRD-001#R8]])
4. 1분 안에 결과 화면이 열린다: 한 문단 요약 + 핵심 포인트 5개 ([[VA-PRD-001#R4]]), 시간순 타임라인 8개 안팎 ([[VA-PRD-001#R5]]), 전체 스크립트 ([[VA-PRD-001#R3]])
5. 요약을 읽고 "볼 가치 있음"을 30초 만에 판단한다

**변형 — 자막이 없는 영상**: 3단계가 "음성 내려받는 중 → 받아쓰기 중 → …"으로 바뀌고 2~3분 걸린다. 나머지는 같다 ([[#S2]] 참조).
**변형 — shorts / youtu.be 링크**: URL 형식이 달라도 같은 흐름 ([[VA-PRD-001#R2]]).

**성공 조건**: URL 입력부터 요약이 보이기까지 1분 이내 ([[VA-PRD-001#N1]]). 요약이 영상 내용과 어긋나지 않는다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R2]], [[VA-PRD-001#R3]], [[VA-PRD-001#R4]], [[VA-PRD-001#R5]], [[VA-PRD-001#R8]], [[VA-PRD-001#N1]]

#### S2 로컬 파일 분석 — 회사 세미나 녹화본

**주체**: [[#P1]]
**상황**: 사내 세미나 녹화본 `seminar.mp4`(40분)가 PC에 있다. 외부 서비스에 올리기 애매해서 내 도구로 돌리고 싶다.

1. 화면에서 파일을 고른다 (또는 경로를 넣는다) ([[VA-PRD-001#R1]])
2. 파일 길이가 60분 이하인지 확인되고 분석이 시작된다 ([[VA-PRD-001#N2]])
3. 진행 상태: "음성 추출 중 → 받아쓰기 중(OpenAI) → 요약 만드는 중 → 타임라인 만드는 중" ([[VA-PRD-001#R8]])
4. 3분 안에 [[#S1]] 4단계와 같은 결과 화면이 열린다
5. 화면 한쪽에 "이 파일의 음성 트랙이 OpenAI로 전송되었습니다"가 보인다 ([[VA-PRD-001#N3]])

**변형 — 음성 파일(mp3)**: 1단계에서 mp3를 골라도 같은 흐름. 음성 추출 단계만 건너뛴다.
**변형 — 영상이 아닌 파일**: pdf를 고르면 1단계에서 "영상·음성 파일이 아닙니다"라고 알려 주고 멈춘다.
**변형 — 한국어 발표**: 받아쓰기가 한국어를 자동 감지한다. 요약은 어차피 한국어 ([[VA-PRD-001#R3]], [[VA-PRD-001#R4]]).

**성공 조건**: 40분 파일 → 3분 이내 ([[VA-PRD-001#N1]]). 원본 파일과 결과는 PC에만 남는다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R1]], [[VA-PRD-001#R3]], [[VA-PRD-001#R8]], [[VA-PRD-001#N1]], [[VA-PRD-001#N2]], [[VA-PRD-001#N3]]

#### S3 타임라인으로 원하는 구간 찾기

**주체**: [[#P1]]
**상황**: [[#S1]]의 발표를 보기로 했지만, 앞부분 회사 소개는 건너뛰고 본론부터 보고 싶다.

1. 결과 화면의 타임라인을 훑는다. 구간마다 `mm:ss 제목 — 한 줄 설명`이 보인다 ([[VA-PRD-001#R5]])
2. "12:40 아키텍처 개요" 구간을 누른다
3. 스크립트가 12:40 위치로 이동해 그 부분 대사가 강조된다 ([[VA-PRD-001#R3]])
4. 시각을 보고 YouTube에서 그 지점부터 재생한다

**변형 — 스크립트에서 거꾸로**: 스크립트를 읽다가 흥미로운 문장을 누르면 그 문장의 시각이 보인다.

**성공 조건**: 구간 시각이 실제 영상의 해당 장면과 ±10초 안에서 맞는다.
**연관 요구사항**: [[VA-PRD-001#G1]], [[VA-PRD-001#R3]], [[VA-PRD-001#R5]]

#### S4 영상에 질문하기

**주체**: [[#P1]]
**상황**: [[#S1]]의 발표 요약을 읽었는데, 발표자가 어떤 DB를 썼는지가 요약엔 없다.

1. 결과 화면의 질문창에 "어떤 DB를 썼어?"라고 묻는다 ([[VA-PRD-001#R6]])
2. 답이 온다: "PostgreSQL을 썼고, 벡터 검색은 pgvector 확장으로 처리했다고 합니다. (근거 23:15, 24:02)"
3. 근거 시각을 누르면 스크립트의 그 위치로 이동한다 ([[VA-PRD-001#R3]])
4. 이어서 "그거 성능은 어땠대?"라고 묻는다. "그거"가 pgvector를 가리키는 걸 이해하고 답한다
5. "발표자 회사 매출은?"이라고 묻자 "이 영상에서는 다루지 않습니다"라고 답한다

**변형 — 스크립트가 긴 경우(60분)**: 답변 시간이 조금 늘 수 있지만 흐름은 같다.

**성공 조건**: 답변마다 근거 시각이 붙고, 그 시각의 대사가 실제로 답의 근거다. 영상에 없는 걸 지어내지 않는다.
**연관 요구사항**: [[VA-PRD-001#G2]], [[VA-PRD-001#R6]], [[VA-PRD-001#R3]]

#### S5 며칠 뒤 다시 열어 질문하기

**주체**: [[#P1]]
**상황**: 일주일 전 분석한 발표 내용이 갑자기 필요하다. 링크는 기억 안 나고 제목만 어렴풋하다.

1. 화면의 "분석한 영상" 목록을 연다. 제목·채널·분석 날짜가 보인다 ([[VA-PRD-001#R7]])
2. 해당 영상을 골라 연다. 요약·타임라인·스크립트가 그대로 있다. 다시 분석하지 않는다
3. 새 질문을 한다 ([[VA-PRD-001#R6]]). 이전 질문 기록도 남아 있다
4. 필요 없어진 다른 영상 하나를 목록에서 삭제한다

**변형 — 같은 링크를 또 넣음**: 새로 분석하지 않고 "이미 분석한 영상입니다"라며 저장된 결과를 연다 ([[VA-PRD-001#R7]]).
**변형 — 같은 로컬 파일을 또 넣음**: 파일 내용이 같으면 마찬가지로 저장된 결과를 연다.

**성공 조건**: 다시 여는 데 API 호출 없이 즉시 열린다. 삭제하면 목록·결과·스크립트가 모두 지워진다.
**연관 요구사항**: [[VA-PRD-001#G2]], [[VA-PRD-001#G3]], [[VA-PRD-001#R6]], [[VA-PRD-001#R7]], [[VA-PRD-001#N3]]

#### S6 잘 안 되는 경우들

**주체**: [[#P1]]
**상황**: 처음 설치했거나, 안 되는 입력을 넣었다.

1. **API 키 없이 시작**: 첫 분석을 누르자 "OpenAI API 키가 설정되지 않았습니다 — 설정 방법: …"이 뜨고 분석은 시작되지 않는다 ([[VA-PRD-001#N3]])
2. **비공개·삭제된 YouTube**: URL을 넣자 "이 영상은 비공개이거나 삭제되어 받을 수 없습니다"가 뜬다 ([[VA-PRD-001#R2]])
3. **90분짜리 영상**: 제목·길이를 가져온 뒤 "60분을 넘는 영상은 아직 지원하지 않습니다(90:12)"라며 시작 전에 멈춘다 ([[VA-PRD-001#N2]])
4. **분석 도중 실패**: 받아쓰기 단계에서 API 오류가 나면 "받아쓰기 단계에서 실패: (이유)"가 뜨고, 다시 시도할 수 있다 ([[VA-PRD-001#R8]])

**변형 — 인터넷 끊김**: 로컬 파일이라도 받아쓰기는 API라서 "네트워크에 연결할 수 없습니다"로 4단계와 같이 처리된다.

**성공 조건**: 어떤 실패든 "무엇이, 어느 단계에서, 왜" 안 됐는지 한 줄로 알 수 있고, 프로그램이 죽지 않는다.
**연관 요구사항**: [[VA-PRD-001#G3]], [[VA-PRD-001#R2]], [[VA-PRD-001#R8]], [[VA-PRD-001#N2]], [[VA-PRD-001#N3]], [[VA-PRD-001#N4]]
