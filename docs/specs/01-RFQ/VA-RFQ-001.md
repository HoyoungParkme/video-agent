# RFQ — 요구·인터뷰

## 1. 배경과 동기

영상을 읽고 내용을 분석해 주는 에이전트를 만들고 싶다. 참조 서비스는 **릴리스 AI(Lilys AI)** — 영상을 넣으면 요약과 타임라인을 만들어 주고, 내용에 대해 물어볼 수 있는 서비스와 같은 것을 직접 만들어 보는 것이 목적이다.

개인용·학습용 프로젝트다. 고객 납기나 팀 사용은 없다.

## 2. 명세 체인

이 문서(RFQ)에서 출발해 PRD → 시나리오 → 유스케이스 → 인프라 → 도메인 → UI → API → 시퀀스 → MINISPEC → 구현 카드 순으로 내려간다. 각 단계는 이 문서의 Q 항목을 근거로 참조한다.

## 3. 요구 사항

#### Q1 영상 입력 — 로컬 파일

내 컴퓨터에 있는 영상 파일(mp4 등)을 직접 넣어서 분석할 수 있어야 한다.

#### Q2 영상 입력 — URL

YouTube 같은 링크를 주면 영상을 받아서 분석할 수 있어야 한다.

#### Q3 요약과 타임라인

영상 전체 내용을 요약해 주고, 장면·주제별로 타임스탬프가 붙은 타임라인을 만들어 줘야 한다. 릴리스 AI가 해 주는 것과 같은 형태.

#### Q4 영상 내용 Q&A

분석이 끝난 영상에 대해 질문하면 내용에 근거해 답해 줘야 한다.

#### Q5 사용 형태

웹 UI로 만들어도 되고, 실행 파일로 만들어서 혼자 써도 된다. 어느 쪽이든 상관없다.

## 4. 사용자와 환경

| 항목 | 내용 |
|---|---|
| 사용자 | 본인 한 명. 개인용·학습용 |
| 참조 서비스 | 릴리스 AI (lilys.ai) |
| 개발 환경 | WSL2(Ubuntu) on Windows, Python 3.12, RAM 15GB, **GPU 없음**, ffmpeg 미설치 |
| 저장소 | github.com/HoyoungParkme/video-agent (공개) |

## 5. 첫 프로젝트

릴리스 AI의 핵심 흐름 하나를 끝까지 재현하는 것: 영상 하나를 넣으면 → 요약·타임라인이 나오고 → 그 영상에 대해 질문하고 답을 받는다.

## 6. 미정

- [ ] 음성 받아쓰기(자막·스크립트)를 결과물로 따로 보여줄지 — 요약을 만들려면 내부적으로는 필요하지만, 사용자에게 노출할지는 안 정함
- [ ] 영상 언어 — 한국어 영상만인지, 영어 등 다른 언어도 다룰지
- [ ] 영상 길이 상한 — 몇 분짜리까지 다룰지
- [ ] 화면(장면) 분석까지 할지, 음성만으로 할지 — "영상을 읽는다"가 어디까지인지
- [ ] 웹 UI vs 실행 파일 중 어느 쪽으로 갈지 (Q5)
- [ ] 분석 결과를 저장해 두고 다시 볼 수 있어야 하는지
- [ ] 여러 영상을 한꺼번에 넣는 경우가 있는지
